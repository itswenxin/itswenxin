## [Motion Agent](https://github.com/itswenxin/motion-agent)

Motion Agent is an open-source AI workflow for Adobe After Effects.
**Code, installers and case studies: [github.com/itswenxin/motion-agent](https://github.com/itswenxin/motion-agent)**

It connects an AI coding assistant with an active After Effects project through a local bridge, so the assistant can inspect compositions, create and adjust layers, write expressions, set keyframes, run project checks, and support motion design iteration from natural-language requests.

The goal is not to replace motion designers. The goal is to make repetitive technical work easier, help capture reusable animation patterns, and give designers a faster way to explore ideas while keeping creative control inside After Effects.

### Current Capabilities

- Connects AI assistants with Adobe After Effects through a local bridge
- Reads composition structure, layers, transforms, expressions, and keyframe data
- Creates and modifies layers, controllers, rigs, expressions, and animation timing
- Supports reusable motion cases and project-specific animation references
- Includes local analysis tools for video, audio, frame extraction, and timing checks
- Provides bridge health checks, queue cleanup, and safer command execution

### Design Principles

- Keep the designer in control
- Prefer motion curves, timing, spacing, and path design over visual shortcuts
- Preserve editable After Effects structure whenever possible
- Turn useful project discoveries into reusable cases
- Treat AI output as a collaborator's draft, not an automatic final answer
